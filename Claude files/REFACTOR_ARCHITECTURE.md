# Repository architecture — linear (SSJ) and global solvers

The map of this repository after the restructuring of 2026-09-30 and 2026-10-01.
**No equation, parameter value or solver setting changed** at any step; every step was
verified bit-for-bit against the code before it (§8). All links are relative to this file,
which lives in `Claude files/`.

## 1. The idea

The repository solves one model in two ways. The model is a two-country monetary union with
Gertler–Karadi banks and Bocola-style priced sovereign risk.

- **[linear_ssj/](../linear_ssj/)** linearises the model in sequence space with the
  `sequence_jacobian` library (sticky prices, nominal deposits).
- **[global_projection/](../global_projection/)** solves it globally by Chebyshev–Smolyak
  collocation, with an occasionally-binding leverage constraint.

The two share three things, and nothing else:

- **Calibration**: [calibration/](../calibration/) holds both parameter sets side by side.
  They hold different values, so merging them would change the economics.
- **One entry point**: [run.py](../run.py). It holds the configuration, and the global
  pipeline written out step by step.
- **The results layout and the comparison**: everything goes to `results/`, and
  [compare.py](../compare.py) sets the two impulse responses next to each other.

The model code of each solver is its own package. Neither imports the other, and
[test_isolation.py](test_isolation.py) fails if one ever does. The two solvers need
different interpreters: SSJ runs in the `ssj` conda env, because the base env has a broken
`liblapack`, and the global model runs under plain `python3`. So `run.py` runs the global
model in its own process and the SSJ model as a subprocess.

Documentation, notes, reports and tests written by Claude live in `Claude files/` (this
folder), at the path each would otherwise have had (§7).

## 4. The pipeline

`python3 run.py both` does, in this order:

1. **Compute every selected model, then save.**
   - **SSJ:** the steady state, the IRFs to a +1 pp default shock and a +1% TFP shock, and the TPI.
   - **Global:** the steady state, then the TFP shock. Then the sovereign-risk solve (coarse
     ladder, then the s-refined grid), the model's own rest point, and the impact,
     persistence and dynamic IRFs. Then the output and bond-price decompositions, the Euler
     errors, and (if `RUN_LTRO`) the LTRO sweep.
2. **Plot every model from its saved data**, only after all computing is done.
3. **Compare** the two models.

What each model saves to `results/<MODEL>/data/`:

| SSJ | Global |
|---|---|
| `steady_state`, `irfs` (both shocks, every variable), `tpi`, `comparison_irfs.json` | `settings`, `calibration`, `steady_state`, `tfp_irf`, `rest_point`, `persistence_irf`, `risk_irf`, `output_decomposition`, `bond_decomposition`, `accuracy`, `ltro` (when run), the solved rules `rules_tfp.pkl` / `rules_risk.pkl`, `comparison_irfs.json` |

Read any of them back with `results_io.load("results/GLOBAL/data/risk_irf")`. The console
output of each model is in `results/<MODEL>/run.log`.

## 5. How to run and compare

```bash
python3 run.py                    # MODEL from run.py's configuration ("both")
python3 run.py ssj                # linear model only
python3 run.py global             # global model only (~70-100 min; +~3 h with RUN_LTRO = True)
python3 run.py global --quick     # coarse grid, no LTRO sweep: a ~10 min preview, NOT converged
python3 run.py both --plots-only  # redraw every figure from the saved data, no solving
python3 run.py compare            # the comparison only, from the saved data
```

- **Interpreters.** `SSJ_PYTHON` sits at the top of `run.py` and can be overridden by the
  environment variable of the same name. The global model runs in the `python3` that runs
  `run.py`.
- **Results get replaced.** A compute run empties and rewrites that model's `data/` and
  `figures/`, so a `--quick` preview replaces a full run.
- **The comparison.** `results/COMPARISON/comparison.md` gives, for each shock and each shared
  series:
  - the impact response and the peak response (with its quarter) for both models;
  - a same-sign flag;
  - for the risk shock, the impact response per 1 pp of the default-probability move.

  The overlay figures plot the two paths together.
- **Reading the comparison.** The calibrations differ, and so do the risk shocks:
  - the SSJ shock is +1 pp on the quarterly default rate;
  - the global shock takes p^d (the priced quarterly default probability) from 0.10% to 1.98%.

  So raw magnitudes are not a like-for-like test; signs and shapes are.

## 6. Tests

```bash
python3 -m pytest "Claude files"                                    # SSJ, experiments, regimes, isolation
python3 "Claude files/global_projection/tests/test_state_grid.py"   # global tests run as scripts
```

The global suite is: `test_ss_identities`, `test_fast_kernels`, `test_state_grid`,
`test_decision_rules` and `test_no_unbound_names` (fast), plus `test_collocation` and
`test_recursive_nesting` (minutes each). Nine tests in `test_eba_calibration` need the raw
EBA disclosure files, which are not in `data/`; see `data/README.md` in this folder.

## 7. Conventions

- **One import root.** Everything is imported package-qualified from the repo root:
  `from calibration.ssj import get_calibration`, `from global_projection.blocks.bank import …`.
- **Isolation.** `linear_ssj` and `global_projection` never import each other, and
  `calibration` imports neither (`test_isolation.py`).
- **Claude files.** Documentation, notes, reports, logs and tests written by Claude go in
  `Claude files/`, at their mirrored path. The exceptions are files that tools or code read
  at fixed paths (`CLAUDE.md`, `.claude/`, `.githooks/`, `results/`, and the research inputs
  under `data/`, `Empirics/outputs/`, `experiments/` and `diagnostics/regimes/`). The commit
  hooks require `Claude files/docs/{STATE,PROGRESS,HANDOFF}.md`. Quote the path in shell
  commands.
- **Global code style.** Every module and function in `global_projection/` opens with one
  ALL-CAPS comment saying what it is. Console output lives in `reporting/prints.py`.

| Phases 3–4 | Results go to `results/<MODEL>/`, and figures are drawn from the saved data. | One SSJ solve plotted from memory and from saved data gives 21/21 identical figures. The LTRO figures redraw identically. The full run reproduces the recorded headline numbers. |
| Phase 5 | AI-generated files moved to `Claude files/`. 64 outdated or redundant ones were deleted after review. | All tests pass from their new location, and the hooks enforce the moved docs. |

The full run of 2026-10-01 (`S_REFINE = 5`, LTRO off) reproduces the recorded numbers.
Output's impact response is −0.1105% from the fitted rules and −0.1278% clearing the period
map exactly, the credit spread rises +90.6 bp/yr, and `Q_bD` (the D bond price) falls
